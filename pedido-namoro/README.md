# Adrian & Kaik • Pedido em Namoro — Experiência Interativa

Projeto front-end com foco em animações, microinterações e responsividade, ideal para demonstrar criatividade no portfólio.

## Recursos

- Layout responsivo para celular, tablet e desktop
- Hero com visual cinematográfico e glassmorphism
- Efeito de texto digitando
- Fundo com partículas flutuantes e brilho dinâmico
- Cards com efeito tilt
- Timeline com revelação ao rolar a página
- Cartinha/modal interativa
- Tela final com confetes e corações
- Resposta alternativa respeitosa com mensagem de acolhimento

## Estrutura

- `index.html`
- `styles.css`
- `script.js`

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie os arquivos para a branch `main`.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha:
   - Source: **Deploy from a branch**
   - Branch: **main** / **root**
5. Salve e aguarde a publicação.

## Personalização rápida

Você pode trocar os textos diretamente no `index.html` e no `script.js`.

- Texto principal digitado: variável `text` no `script.js`
- Cartinha: seção `.letter-content` no `index.html`
- Título do pedido: seção `#pedido`
