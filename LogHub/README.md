# LogHub

Central de três ferramentas: CargoQuery, Separador de números e Importar Caixas.

Disponível em https://adrianhenrrique.github.io/LogHub/ após publicação do GitHub Pages.

Os arquivos e planilhas são processados localmente no navegador. Nenhum dado operacional deve ser enviado ao repositório.

Alterações futuras na pasta LogHub são publicadas automaticamente se o GitHub Pages estiver ativado para a branch main na pasta raiz (/).
